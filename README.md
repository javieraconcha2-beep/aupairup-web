# AuPairUp website

Static site for https://aupairup.com, deployed on Vercel (Framework Preset: Other, no build step).

- `index.html`: page shell, meta tags and link preview
- `assets/app.js`, `assets/app.css`: compiled page (React + Tailwind)
- `screens/`, `orbit/`: app images
- Source code: `AuPairUpLanding.tsx` in the AuPairUp Claude project
